1. WEATHER DATA API
--------------------------------------------------------------------------------
• Provider: Open-Meteo Weather API
• URL: https://api.open-meteo.com/v1/forecast
• Type: External REST API (Free, No API key required)
• Used In: src/hooks/useWeather.ts
• Purpose: 
  - Current temperature, apparent temperature ("feels like")
  - Relative humidity, wind speed, weather code, surface pressure
  - Daily sunrise, sunset, maximum UV index
  - 8-slot hourly temperature & weather forecast

--------------------------------------------------------------------------------
2. LIVE LOCATION DETECTION API
--------------------------------------------------------------------------------
• Provider: IPWHOIS.io
• URL: https://ipwho.is/
• Type: External REST API (Automatic IP Geolocation)
• Used In: src/hooks/useLocation.ts & src/app/api/geo/route.ts
• Purpose: 
  - User ki real-time IP address detect karna
  - User ka city, state/region, country code, postal code nikalna
  - Real latitude & longitude aur local timezone (e.g. Asia/Kolkata) nikalna
  - ISP network telemetry (e.g. Fastnet, Airtel, etc.)

5. DATABASE STORAGE (SUPABASE POSTGRESQL via PRISMA)
--------------------------------------------------------------------------------
• Provider: Supabase Database (PostgreSQL)
• Driver: Prisma ORM (@prisma/client)
• Connection: DATABASE_URL & DIRECT_URL (via .env)
• Table: daily_weather_records
• Used In: src/app/api/weather-log/route.ts (triggered via generic src/services/dataService.ts & src/hooks/useDataSync.ts)
• Purpose: 
  - Har baar weather change ya refresh hone par sheher ka naam, temperature aur weather condition 
    Supabase database table 'daily_weather_records' me record save (POST) karna
  - Puraane weather logs retrieve (GET) karna
